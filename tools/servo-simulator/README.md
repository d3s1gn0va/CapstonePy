# CUVO 3D Servo Simulator

`index.html`을 브라우저에서 열면 실행된다. 개발 서버나 인터넷 연결은 필요하지 않다. `index.html`, `styles.css`, `browser.bundle.js`는 같은 폴더에 둔다.

## 조작과 기준

* 각 축의 슬라이더와 숫자 입력으로 자세를 바꾼다. 상대각도/서보 명령값 전환은 자세를 바꾸지 않는다.
* 초기화 아이콘은 고개·정수리 정면과 양팔 내림으로 복귀한다.
* 로봇을 드래그해 시점을 돌리거나 입체/정면/측면/위 시점을 선택한다.
* 춤 선택에서 새 `CUVO Groove` 또는 기존 교대 춤을 고른다. 재생/일시정지, 처음부터, 정지, 시간 탐색과 0.25/0.5/1배속을 지원한다. 수동 서보 입력은 재생을 중단한다.
* `CUVO Groove`는 100BPM/16박이다. 교대 스윙 → 양팔 리듬 → 대각선 포즈 → 깜박임 → 기본 자세 순서이며 준비·복귀를 포함한 가상 실행은 약 12.3초다. 고개·눈길과 정수리의 작은 독립 회전을 포함한다.
* 양팔 팔꿈치는 **사람이 조절하는 프리스탑 120..180도**다. 기본 미리보기는 150도이며 춤이 각도를 바꾸지 않는다. 서보 채널/명령에 포함하지 않는다.
* 눈 모니터와 얼굴에는 실제 OLED 렌더러의 눈구멍/눈동자 그림을 사용한다. 소리 선택은 기본 꺼짐이며 켜면 기록된 타이밍에 오디오를 재생한다.
* 마지막 수동 자세·팔꿈치 각도·입력 모드는 브라우저 저장 기능이 허용되는 경우 기억한다. 미리보기는 자동 시작하지 않는다.

| 축 | 채널 | 서보 범위 | 상대 0의 명령값 | 상대 범위 |
| --- | --- | --- | --- | --- |
| 고개 | CH0 | 45..135 | 90 | -45..45 |
| 오른팔 X | CH1 | 0..180 | 45 | -45..135 |
| 정수리 | CH2 | 45..135 | 90 | -45..45 |
| 오른팔 Y | CH3 | 0..45 | 0 | 0..45 |
| 왼팔 X | CH4 | 0..180 | 135 | -45..135 |
| 왼팔 Y | CH5 | 135..180 | 180 | 0..45 |

좌우는 로봇 자신 기준이다. 고개/정수리 서보 45는 로봇 왼쪽이다. 양팔의 상대 X는 앞으로, Y는 바깥쪽 위로 증가하는 단순화 구조다. 왼팔은 `서보 = 기준값 - 상대각도`로 반대 방향 변환한다.

## 모델과 안전 한계

실제 CAD 모델이 아닌 Three.js의 단순화된 외형이다. 치수·실제 어깨 축 중첩 구조·팔꿈치 굽힘 축/방향·충돌·중량·서보 전류·손상은 검증하지 않는다. 사용자 지정 각도 범위를 표시/제한하지만 실제 로봇의 안전을 검증한 것은 아니다. 팔꿈치 고정 각도를 바꾸면 실제 부하와 공간도 달라진다. SSH, Bluetooth, Serial, GPIO, PWM 기능이 없으며 실물에 명령을 보내지 않는다.

실제 Python 순서 실행기를 가상 장치로 실행한 20ms 간격 기록을 재생한다. 관절 명령의 선형 보간/정수 반올림, 눈 그림과 오디오 순서를 공유하지만 실제 USB 응답 지연·서보 추종·전원 부하는 재현하지 않는다. 처음의 기본 자세는 측정값이 아닌 미리보기의 기준 자세다. [공유 구조와 안무 편집](../../docs/22_OFFLINE_CHOREOGRAPHY_PREVIEW.md)을 따른다.

## 수정과 검사

`build.mjs`는 `export_simulation.py`로 실제 실행 결과와 OLED 그림을 기록하고 브라우저 번들에 포함한다. 설정/실행 코드 수정 후에는 다시 빌드해야 한다. 브라우저에서 별도로 춤 궤적을 계산하지 않는다. 기존 로봇 프로필과 Pi의 기본 춤은 이 도구에서 수정하지 않는다.

빌드에는 Pillow가 설치된 Python 3와 Node.js가 필요하다. Python 경로가 다르면 `CUVO_PYTHON=/absolute/path/to/python3`를 지정한다. 짧은 타악기 WAV는 표준 라이브러리로 생성하며 외부 음원을 내려받지 않는다.

```sh
pnpm install --ignore-scripts
pnpm build
pnpm test
pnpm test:browser
```

브라우저 검사는 설치된 Chrome을 사용한다. 1440/820/390/320px에서 캔버스 픽셀, 모델 프레이밍, 각도 변경에 따른 픽셀/좌표 변화, 입력 보정, 고개-정수리 중첩, 팔꿈치 고정, 실제 눈 그림, 탐색/일시정지/속도, 춤 끝까지 재생과 기본 자세 복귀, 가로 넘침 및 외부 통신 부재를 확인한다. 결과와 캡처는 Git 제외 폴더 `test-output/`에 저장한다.
