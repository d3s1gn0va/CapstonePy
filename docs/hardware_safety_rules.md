# Hardware Safety Rules

## 서보 전원

MG996R 같은 고토크 서보는 Raspberry Pi나 Arduino의 5V 핀에서 직접 전원을 공급하지 않는다. 서보에는 충분한 전류를 낼 수 있는 외부 5V 전원을 사용한다.

## 공통 접지

Raspberry Pi, Arduino Mega, PCA9685, 서보 외부 전원은 반드시 GND를 공통으로 연결한다. 공통 접지가 없으면 PWM 기준이 흔들려 서보가 튀거나 통신이 불안정해질 수 있다.

## PCA9685 VCC와 V+

PCA9685의 `VCC`는 로직 전원이며 Arduino 또는 Raspberry Pi의 로직 레벨에 맞춘다. `V+`는 서보 전원 입력이며 외부 5V 서보 전원을 연결한다. `VCC`와 `V+`의 역할을 혼동하지 않는다.

## 5V 유지

SG92R과 MG996R 서보 전원은 5V 기준을 유지한다. 전압 강하가 크면 서보 떨림, 리셋, USB Serial 끊김이 발생할 수 있다.

## 안전 각도 확장 원칙

서보 안전 범위를 넓히기 전에는 실제 기구물의 충돌, 링크 간섭, 서보 과부하 가능성을 먼저 경고하고 확인한다. 한 번의 변경으로 안전 범위를 5도보다 크게 넓히지 않는다. 실제 서보 테스트는 작은 각도 변화부터 진행한다.
