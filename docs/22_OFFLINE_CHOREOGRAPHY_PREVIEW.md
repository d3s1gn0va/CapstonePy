# 22 Offline Choreography Preview

## 현재 결과 (2026-10-18)

`tools/servo-simulator/index.html`을 열고 `CUVO Groove`를 재생한다. 서버·인터넷·Pi 연결은 필요 없다. 새 춤은 미리보기 전용으로 준비했으며 Pi에 설치된 기존 교대 춤, BLE 기본 동작, 펌웨어, 프로필과 검증 플래그는 바꾸지 않았다.

선택한 춤은 기존 유행 춤의 전체 복제가 아닌 CUVO 전용 상체 그루브다. 다리·몸통 기울임이나 능동 팔꿈치 없이도 팔의 교대/동시 움직임, 어깨 두 축, 고개·정수리 및 눈의 연동 차이가 드러나도록 구성했다. 실제 기구에서 가장 좋아 보인다는 검증은 아직 아니다.

| 구간 | 동작 |
| --- | --- |
| 준비 1.2초 | 기준 자세에서 시작 |
| 1..8박 | 양팔 교대 스윙, 고개와 아래 대각선 시선, 정면 모으기 |
| 9..12박 | 양팔을 함께 들고 내리며 눈의 열림 정도 변경 |
| 13..14박 | 좌우 대각선 포즈, 고개와 정수리의 작은 반대 상대 회전 |
| 15..16박 | 양팔 포즈와 깜박임 |
| 복귀 1.2초 | 여섯 축의 상대 0으로 복귀 |

100BPM/한 박 600ms/16박이다. 명목 합계 12초, 가상 실행기 전환 간격을 포함한 기록은 12.34초다. 상대 X 0..55, Y 0..35, 고개 -20..20, 정수리 -8..8도를 사용한다. 고개/정수리는 90도 기준, 팔 원점/역방향 변환은 [현재 프로필](08_CALIBRATION_AND_SAFETY.md)을 따른다. 정수리는 고개에 장착되므로 화면의 전역 회전에는 고개 회전도 더해진다.

팔꿈치는 사용자 지정 **120..180도 수동 프리스탑**이며 180도가 완전히 펴진 상태다. 미리보기 기본값은 150도다. 사람이 선택한 각도로 유지하고 안무에는 서보 축이나 시간별 팔꿈치 목표를 만들지 않는다. 실제 고정 각도에 따라 팔끝 궤적과 어깨 하중이 달라진다.

## 하나의 실행 기준

1. `raspberry_pi/robot_demo/choreographies/cuvo_groove.json`에 상대 여섯 축 목표, 박자/시간, 눈 자세, 타악기 종류를 정의한다.
2. `choreography.py`가 기존 `Step`으로 변환한다. 프로필 범위, 필드/축, 시간, 고정 팔꿈치 메타데이터, 오디오 허용 목록과 마지막 기본 자세를 검사한다.
3. `dance_sequence.py`와 실제 `IntegratedSequence`를 가상 장치로 실행한다. `export_simulation.py`는 20ms 간격 관절값, 눈 그림, 단계와 소리 시점을 기록한다.
4. `build.mjs`가 기록·PNG 눈 그림·WAV를 번들에 넣는다. 브라우저는 기록만 재생하며 별도 JavaScript 안무/완화 곡선을 만들지 않는다.

관절 보간은 Mega 명령의 선형 이동/양수 반올림에 맞춘 이상화 모델이다. OLED는 기존 `EyeRenderer`의 실제 128x128 프레임과 눈구멍 마스크를 그대로 쓴다. CAD 눈구멍 +3px, 선 두께와 좌우 배치를 별도 근사 타원으로 대체하지 않는다. 소스 해시를 함께 표시해 어떤 코드로 만든 기록인지 구분한다.

기존 `dance_config.json`도 동일한 실행기를 통해 기록해 선택 메뉴에 남겼다. 새 schema 2를 실제 실행 진입점 `integrated_demo.py --action dance --dance-config PATH`에서 읽을 수 있도록 했지만, **이번에는 실물 실행하지 않았으며 기존 하드웨어 확인 잠금을 우회하지 않는다**. BLE의 제한된 기존 춤을 새 춤으로 교체하거나 자동 배포하지 않는다.

## 편집과 확인

안무 JSON을 수정하고 시뮬레이터 폴더에서 다시 빌드한 뒤 브라우저를 새로고침한다. Node.js 의존성은 잠금 파일을 사용한다. Python 3에는 Pillow가 필요하며 `CUVO_PYTHON`으로 실행 경로를 지정할 수 있다.

```sh
pnpm build
pnpm test
pnpm test:browser
```

저장소 루트의 Python 검사는 패키지 이름 충돌을 피하도록 다음처럼 실행한다.

```sh
python3 -m unittest discover -s tests -t .
```

생성된 `simulation-data.json`과 `test-output/`은 Git 제외 대상이며 배포된 HTML은 `styles.css`, `browser.bundle.js`와 함께 둔다. 타악기 세 개는 `scripts/generate_groove_audio.py`가 직접 합성한 짧은 PCM WAV다. 소리는 기본 꺼짐, 명시적으로 켜면 브라우저에서만 재생한다.

## 한계와 다음 단계

이것은 움직임 순서/명령값/눈·음성 연출의 미리보기다. 실제 CAD, 질량·중력, 접촉/충돌, 전압·전류, 서보 손상·지연·백래시는 모델링하지 않는다. 가상 ACK와 20ms 표본 간격은 실제 USB/PWM 실행 주기와 같다는 뜻이 아니다. 시작 기본 자세도 센서로 측정한 실제 위치가 아니다.

Pi 전송 전에 선택한 팔꿈치 각도를 실제 기구에 맞추고 여유 공간·고정 상태·5V 공급·동시 부하를 다시 확인한다. 새 춤은 정수리도 포함하므로 이전 5축 춤 시험을 새 안무 전체의 검증으로 간주하지 않는다. 프로필의 `verified`/`power_verified=false`와 기존 실물 실행 보호는 유지한다.
