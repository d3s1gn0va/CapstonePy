# 02 Robot Design

## 최신 추가: 수동 팔꿈치 (2026-10-18)

양팔 팔꿈치는 180도 완전 펼침부터 120도 굽힘까지 사람이 움직여 고정하는 프리스탑 구조다. 서보로 실시간 제어하지 않으므로 기존 6축 구성과 채널은 늘어나지 않는다. 춤은 고정된 팔꿈치 상태에서 어깨 X/Y를 움직인다. 시뮬레이터는 기본 150도, 좌우 각각 120..180도 수동 설정을 제공하지만 실제 굽힘 축/치수와 부하 검증은 아니다.

현재 서보 원점/범위는 [2026-10-13 기준](08_CALIBRATION_AND_SAFETY.md)을 따른다. 아래 2026-10-05 미확정 각도와 3채널 설명은 이전 기록이다.

## 사용자 지정 최신 기구 구성

2026-10-05 기준 이름은 CUVO이며 서보는 모두 SG92R이다. 고개 회전 1축, 카메라가 달린 정수리 회전 1축, 양팔 어깨 X/Y 각 1축으로 총 6축이다. X/Y의 실제 회전 방향, 서보혼 기준 자세, 팔 무게와 안전 각도는 확인 필요다. 두 눈은 각각 SH1107 OLED 한 장을 사용한다.

전체 배치 계획은 [16_FULL_SYSTEM_WIRING_PLAN.md](16_FULL_SYSTEM_WIRING_PLAN.md)를 따른다. 기존 3채널 동작을 새 양팔 네 축에 그대로 적용하지 않는다.

사용자 후속 지정: 로봇 자신의 오른팔은 내린 자세를 상대 0도로 본다. X축의 요청 범위는 -45..45도, 옆으로 들어 올리는 것으로 설명한 Y축은 0..45도다. 실제 서보 명령값/방향과 좌측 팔 범위는 미확정이다. [상대 각도와 보정](08_CALIBRATION_AND_SAFETY.md#새-오른팔의-상대-각도-2026-10-05)을 따른다.

## 현재 3채널 코드의 기구 역할

현재 코드와 주석에서 확인되는 구동 부위:

* 고개: SG92R 서보 사용, PCA9685 Channel 0
* 로봇 기준 오른팔 기존 한 축: PCA9685 Channel 1 (과거 MG996R 주석은 최신 모델 지정과 다름)
* 카메라가 달린 정수리 회전: PCA9685 Channel 2

Arduino 코드 주석에 따르면 현재 펌웨어의 초기 목적은 다음과 같다.

* Raspberry Pi 연결 전 Arduino IDE Serial Monitor에서 단독 시험
* 서보혼을 분리한 상태로 중앙값 맞추기
* 실제 기구물 조립 후 안전 각도 캘리브레이션
* 지정 시간 동안 부드럽게 이동

## 기존 3채널 동작 자세

Raspberry Pi `config.py` 기준:

* `HEAD_NEUTRAL_DEG = 0`: 고개 기본 자세
* `HEAD_LEFT_DEG = 70`: 버튼 시퀀스에서 고개 이동 목표
* `ARM_DOWN_DEG = 90`: 오른팔 초기 자세
* `ARM_UP_DEG = 180`: 오른팔 상승 자세

이 오른팔 각도는 기존 한 축의 설정이며 새 양팔 어깨 네 축의 확정 자세가 아니다.

## 외형과 구조

확인된 사실:

* 고개, 오른팔, 카메라 좌우 회전은 각각 독립 서보로 움직인다.
* 팔 서보는 로봇 기준 오른팔 역할이다.

미확정:

* 전체 외형 이미지
* 머리와 팔의 실제 링크 구조
* 서보혼 방향과 기구 기준 좌표계
* 몸체 크기, 재료, 마감, 조립 방식
* 전원, Raspberry Pi, Arduino, PCA9685의 실제 장착 위치

## 주의

고개 0도에서 180도 전체 범위 이동은 현재 Arduino 안전 범위 안에 있더라도 실제 기구물 충돌 가능성이 있다. 최종 전시 동작으로 확정된 것이 아니며, 실행 전 실제 기구물 간섭을 확인해야 한다.
