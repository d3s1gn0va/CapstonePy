# CUVO 전시와 앱 에셋 준비 목록

2026-10-05 기준. [전시와 앱 계획](17_EXHIBITION_AND_APP_PLAN.md)의 관람자 직접 조작 / 예시 기록 체험에 필요한 자료를 정리한다. 새로 우선 준비할 원본은 **실제 CUVO 대표 이미지 한 장과 사용 가능한 예시 영상 한 개**다. 로고, 추가 렌더, 추가 영상은 그다음 순서로 준비한다.

이 목록은 저장소에서 확인한 파일과 앞으로 필요한 자료를 구분한 계획이다. 대화에 첨부됐거나 다른 폴더에 있는 자료가 없다는 뜻은 아니다. 앱용 최종 원본이 저장소에 등록됐는지, 공개/사용 허가가 있는지는 별도로 확인한다.

## 우선 준비할 자료

P0는 최소 체험에 우선 필요한 자료, P1은 완성도를 위한 자료, P2는 후속 확장이다. 파일 형식과 크기는 제작 권장안이며 아직 확정된 앱 사양이 아니다.

| 우선순위 | 에셋 | 용도 | 원본과 수량 | 현재 상태 |
| --- | --- | --- | --- | --- |
| P0 | CUVO 대표 이미지 | 홈과 기기의 제품 표시 | 현재 외형의 정면 또는 정면 사선 사진/렌더 1장. PNG/WebP, 긴 변 1200px 이상 권장 | 저장소에 제품 이미지 원본 미등록. 기존 첨부/외부 원본 확인 필요 |
| P0 | 예시 놀이 영상 | 기록 목록에서 실제 재생할 예시 | 사용 허가가 확인된 짧은 클립 1개. MP4 권장, 원본 유지 | 저장소에 미등록. 영상 내용과 사용 범위 확인 필요 |
| P0 | 영상 썸네일 | 예시 기록 목록 | 클립에서 대표 장면 1장 추출. PNG/WebP | 영상 준비 후 제작 가능 |

| P1 | 한글 폰트와 사용권 정보 | 앱 전체 타이포 | DESIGN.md의 Pretendard를 우선 후보로 사용. 웹용 WOFF2 및 라이선스 | 저장소에 폰트 미등록. 초기에는 시스템 한글 폰트로 대체 가능 |
| P1 | 제품 보조 이미지 | 눈/정수리/팔 기능을 설명 | 동일한 CUVO의 측면, 눈 확대, 팔 동작 사진/렌더 중 필요한 것만 1~3장 | 미등록. 실제 기능 설명에 필요한 화면이 정해진 뒤 준비 |
| P1 | 추가 예시 기록 | 여러 기록을 살펴보는 체험 | 사용 가능한 클립 1~2개와 파생 썸네일/정보 | 최소 체험은 영상 1개로 시작 가능 |
| P2 | 대여 서비스 설명 자료 | 기기의 서비스 소개 | 대여 -> 가정 놀이 -> 기록 참고 -> 반납을 설명하는 간단한 도식 | 서비스 설명 확정 후 제작. 실제 운영 기능으로 표시하지 않음 |
| P2 | 전시 접속 QR | 개인 휴대폰 접속 또는 안내물 | 전시 연결 방식과 주소 확정 후 생성 | 지금은 불필요. 전시용 휴대폰 한 대가 기본 제안 |

사진/렌더는 지금의 CUVO 외형과 눈 표현에 맞는 자료를 사용한다. 과거 버전이면 버전을 구분하고 새로운 로봇 외형이나 로고를 임의로 만들지 않는다. 홈 이미지가 시작 버튼과 상태를 밀어내는 큰 장식 영역이 되지 않게 한다.

예시 영상은 짧은 놀이 장면을 보여줄 수 있는 승인된 자료를 우선한다. 자료가 없으면 영상 준비 전 상태나 명확히 구분한 스토리보드로 대체한다. AI 생성 아이 영상이나 다른 아이 영상을 실제 관찰 기록으로 꾸미지 않는다. 영상은 자동 재생하지 않는다.

## 이미 있는 자료

| 에셋 | 현재 경로 | 재사용 범위 |
| --- | --- | --- |
| 첫 번째 음성 | `raspberry_pi/robot_demo/audio/01_name_call.wav` | 로봇 이름 부르기. 약 1.437초; 코드 주석상 지우야~ |
| 두 번째 음성 | `raspberry_pi/robot_demo/audio/02_lets_play.wav` | 함께 놀자는 음성. 약 1.907초 |
| 뜬 눈과 감은 눈 | `docs/assets/eye_preview/open.png`, `closed.png` | 앱의 눈 표현 예시 또는 개발 확인용 |
| 좌우 시선 이미지 | `docs/assets/eye_preview/look_left.png`, `look_right.png` | 기기 화면의 표현 예시 또는 개발 확인용 |
| 깜박임 미리보기 | `docs/assets/eye_preview/blink.gif` | 현재 표현 참고. 앱에서 사용할 크기/반복 방식은 별도 검토 |
| 좌우 보기 미리보기 | `docs/assets/eye_preview/gaze.gif` | 기존 시선 표현 참고 |
| 눈구멍 CAD와 설정 | `docs/assets/cad_exports/eye_opening_left.dxf`, `raspberry_pi/robot_demo/oled_aperture.json`, `oled_pair_calibration.json` | 로봇 눈 매핑 원본. 앱용 장식 이미지와 구분 |

눈은 CAD + 3픽셀 확장, 연속선 두께 10픽셀의 승인된 표현을 유지한다. 앱을 만든다는 이유로 새 눈 디자인이나 매핑을 요구하지 않는다. 실제 OLED 애니메이션은 기존 렌더러와 동작 설정을 통합해 실행하는 기능이며 GIF를 OLED에 그대로 재생하는 기능이 아니다.

PNG/GIF는 기존 개발 미리보기다. 앱에 넣기 전 최신 설정과의 일치와 표시 크기를 확인하고, 필요하면 현재 설정에서 다시 내보낸다. 매핑 변경이나 새 눈 디자인을 뜻하지 않는다.

기존 두 WAV는 사용자가 GitHub 포함을 허용한 자료다. 앱/전시의 최종 음원 사용권과 대사 적합성은 별도로 확인한다. 프로필 이름을 바꿔도 고정 녹음이 자동으로 그 이름을 부르지는 않는다. 새 대사 녹음이나 TTS는 별도 요청이 있을 때 추가한다.

## 구현하면서 만들 수 있는 자료

* **아이콘:** 홈, 기록, 기기, 재생, 중단, 좌우 보기, 연결 상태, 북마크, 메모, 닫기, 운영 설정을 일관된 아이콘 라이브러리로 구성한다. 사용자에게 개별 아이콘 파일 제작을 요구하지 않는다.
* **썸네일과 영상 정보:** 준비된 영상에서 장면을 추출하고 재생 길이를 확인한다. 임의의 기록 날짜나 횟수를 실제 수치처럼 채우지 않는다.
* **예시 메모:** 영상에 실제로 보이는 행동을 짧게 기술한다. 발달 점수, 정상/위험, 임상 해석을 새로 붙이지 않는다.
* **앱 상태 문구:** 대기 / 요청 중 / 실행 중 / 복귀 중 / 완료 / 중단 / 오류는 실제 이벤트와 연결한다. 상태마다 장식 이미지나 효과음을 새로 만들 필요는 없다.
* **QR:** 통신 방식 확정 후 필요한 경우에만 생성한다. 비밀번호, 제어 권한 값, 개인키를 공개 문서나 저장소에 넣지 않는다.

색상과 간격은 디자인 설정으로 관리한다. 버튼, 색면, 상태 표시를 모두 이미지 파일로 만들지 않는다. 새 웃는 눈, 새 몸짓 자세, 개인 휴대폰 온보딩, 의료기관 전송 화면은 현재 최소 체험의 필수 에셋이 아니다.

## 보관 위치 제안

기존 WAV, CAD, 눈 미리보기는 현재 위치를 유지한다. 새 앱 에셋을 가져올 때 아래 위치를 사용하는 안을 제안한다. **아래 폴더와 파일은 이번 목록 작성에서 생성하지 않았다.**

```text
docs/assets/app/
  brand/       로고 원본과 사용 정보
  product/     CUVO 제품 이미지
  records/     공개 사용이 승인된 예시 영상, 썸네일, 예시 정보
  fonts/       선택한 웹 폰트와 라이선스
  ASSET_SOURCES.md   출처, 권리, 버전, 예시 여부
```

각 자료의 출처, 제작자/촬영자, 사용 가능한 범위, 공개 허용 여부를 함께 기록한다. 실제 이름, 얼굴, 병원 정보, 화면 속 개인정보와 사진 위치 메타데이터가 포함됐는지 확인한다. 앱에서 쓸 수 있다는 것과 Public GitHub에 원본을 올려도 된다는 것은 별개의 확인이다. 비공개 원본이나 허가되지 않은 영상은 저장소에 넣지 않는다.
