# 00 Project Brief

> 최신 소스 인수인계는 [CURRENT_SOURCE.md](../CURRENT_SOURCE.md), 실제 운용 상태는 [09_CURRENT_STATE.md](09_CURRENT_STATE.md)를 우선한다. 아래 초기 1차 심사/3채널 요약은 이전 기록이며 현재 6축 BLE 구현 부재를 뜻하지 않는다.

## 프로젝트 성격

이 저장소는 산업디자인 캡스톤디자인 로봇 프로젝트의 단일 기준 저장소다. 현재 목표는 1차 심사용 워킹 프로토타입을 안정적으로 관리하고, 새로운 Codex 대화에서도 저장소 문서만 읽으면 프로젝트 맥락과 안전 경계를 이해할 수 있게 하는 것이다.

## 제품 목적

이 프로젝트는 아이의 일상 속 자연스러운 상호작용을 유도하고, 사회적 의사소통 행동을 반복적으로 관찰할 수 있는 가정용 상호작용 로봇 경험을 제안한다.

## 현재 프로토타입 목표

현재 구현은 전시 버튼을 한 번 누르면 로봇이 정해진 짧은 시퀀스를 수행하는 워킹 프로토타입이다.

확인된 시퀀스:

1. 고개 회전과 기존 오른팔 상승을 함께 시작하면서 `01_name_call.wav` 재생
2. 이동/첫 음성 완료 후 대기하고 `02_lets_play.wav` 재생
3. 짧게 유지 후 고개와 기존 오른팔을 초기 자세로 복귀

시연 중 추가 버튼 입력은 무시된다.

## 시스템 요약

* Raspberry Pi: 버튼 입력, 눈 화면, 카메라 영상, WAV 음성 재생, 전체 타임라인 제어
* Arduino Mega 2560: USB Serial 명령 수신, 서보 명령 처리
* PCA9685: Arduino에서 제어하는 PWM 서보 드라이버
* 최신 사용자 지정: CUVO의 고개 1축, 카메라가 달린 정수리 1축, 양팔 어깨 X/Y 4축 모두 SG92R (총 6개)
* Pi에 남아 있는 기존 프로그램은 PCA9685 Channel 0/1/2만 제어하며 최신 서보 시험을 위해 중지한 상태다. 버튼 3개는 비활성이고 기존 자동 실행 등록은 남아 있다.
* 두 눈: 1번 SH1107 SPI OLED 두 장, 독립 시험 완료; Mac의 별도 6축 통합 실행부에 눈/음성 타임라인 추가, 미배포
* [로봇 동작 통합](19_ROBOT_INTEGRATION.md): 앱 제외, 그룹 명령과 90도·0도 고정 시험 펌웨어는 승인 후 Mega 업로드 완료. 마지막 6채널 순차 0도 명령 완료를 확인했으나 실제 안전/초기 자세는 미확정이며 통합 실행은 잠겨 있다.
* [전체 6축 배선 및 전원 계획](16_FULL_SYSTEM_WIRING_PLAN.md): 신규 채널 배정은 계획 단계이며 전원 용량과 어깨 자세 확인이 필요

## 개발 및 운영 원칙

* Python 설정 변경과 Arduino 펌웨어 변경을 구분한다.
* 전시 기능과 개발 중 임시 시험 기능을 구분한다.
* Raspberry Pi 배포 후에는 상태와 로그를 확인한다.
* 요청한 코드 변경에 필요한 Arduino 업로드는 사용자 최신 위임에 따라 검사/중지/검증/PING 확인 후 재승인 없이 진행할 수 있다. 요청하지 않은 전체 범위 서보 시험은 자동 실행하지 않는다. `AGENTS.md`와 현재 상태를 우선한다.
* 공개 저장소에 SSH 키, 비밀번호, 토큰, `.env`, `scripts/local.env`, 로그 파일을 포함하지 않는다.
